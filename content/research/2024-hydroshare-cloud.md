A key milestone in 2024 was the successful migration of HydroShare to a **modern commercial cloud-based system**, improving system performance, scalability, and long-term sustainability.

This transition adopted modern architecture patterns including containerized services orchestrated with Kubernetes, infrastructure-as-code deployments, and automated integration and deployment pipelines. The migration enabled better tools for monitoring and managing data storage quotas and opened the door to new cost-recovery options.

**Improvements delivered:**
- Simplified file upload process with enhanced support for common file types
- Improved metadata for better discoverability, including NSF PAR reporting integration
- New login system using trusted partner credentials, with automatic approval for .edu, .gov, and .org accounts
- Averaging approximately 100 new user accounts per month, with nearly 80% being graduate students, faculty, or staff

In 2025, HydroShare ran reliably with minimal downtime and continued performance improvements following the cloud migration. DOI registration was transitioned from Crossref to DataCite, better aligning with FAIR data principles and improving integration into global data-sharing networks.

HydroShare is at [hydroshare.org](https://www.hydroshare.org/), and its release notes are on [GitHub](https://github.com/hydroshare/hydroshare/releases). Covered in the [CUAHSI 2024 Annual Report](/documents/annual-reports/annual-report-2024.pdf) and the [CUAHSI 2025 Annual Report](/documents/annual-reports/annual-report-2025.pdf).
